# mainframev/homebrew-tap

Homebrew formulae for [mainframev](https://github.com/mainframev)'s tools.

```sh
brew install mainframev/tap/bastian
```

| Formula | Description |
|---------|-------------|
| [bastian](https://github.com/mainframev/bastian) | Terminal Markdown reader |

Formulae are updated automatically by each project's release workflow.
